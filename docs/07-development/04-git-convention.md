# Git Convention

## Branch Protection
- main — Production-ready code (dilindungi)
- develop — Integration branch
- feature/* — New feature
- fix/* — Bug fix
- refactor/* — Refactoring
- docs/* — Documentation

## Workflow (GitHub Flow)
1. Branch dari main: feature/add-booking-module
2. Kerjakan dengan commit kecil
3. Push dan buka Pull Request
4. PR di-review minimal 1 orang
5. Squash merge ke main
6. Hapus branch setelah merge
