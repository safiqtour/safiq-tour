# Safiq Tour

System Architecture Documentation

Version : 1.0

---

# 1. Vision

Safiq Tour adalah Web Application untuk Travel Umroh yang terdiri dari dua domain utama.

1. Public Website
2. Admin Dashboard

Target:

- SEO Friendly
- Fast
- Secure
- Modular
- Scalable
- Vendor Independent

---

# 2. Architecture Style

Architecture Pattern

Monolith Modular

Reason

- MVP lebih cepat dikembangkan.
- Mudah dipelihara.
- Tidak ada kompleksitas microservices.
- Siap berkembang menjadi modular services di masa depan.

↓

↓

Domain

↓

- UI

- Business Logic
- Validation Flow

# 25. Anti Vendor Lock-in

Mandatory Rules

Database must never depend on storage provider.

Storage provider must be replaceable.

No provider-specific business logic.

No provider SDK inside UI.

Repository never uploads files.

Storage abstraction only.

# 27. Architecture Principles

Single Responsibility

Separation of Concerns

Dependency Inversion

Composition over Inheritance

Convention over Configuration

Keep Business Logic in Service Layer

Keep Database Access in Repository Layer

Frontend Never Accesses Database Directly

Storage Independent from Database

Build MVP First

Scale Later
