# Authentication

POST

/api/auth/login

Description

Administrator Login

Request

```json
{
  "email": "admin@safiqtour.com",
  "password": "password"
}
```

Success

```json
{
  "success": true
}
```

Failure

```json
{
  "success": false,
  "message": "Invalid credentials"
}
```

---

POST

/api/auth/logout

Destroy Session

Response

```json
{
  "success": true
}
```

---

GET

/api/auth/session

Return Current Session

---

# Packages API

GET

/api/packages

Description

Return all packages.

Response

```json
{
  "success": true,
  "data": []
}
```

---

GET

/api/packages/:id

Return package detail.

---

POST

/api/packages

Create package.

Request

```json
{
  "name": "",
  "price": 0,
  "airline": "",
  "makkahHotel": "",
  "madinahHotel": "",
  "departureDate": "",
  "thumbnailUrl": ""
}
```

Response

```json
{
  "success": true
}
```

---

PUT

/api/packages/:id

Update package.

---

DELETE

/api/packages/:id

Delete package.

---

# Upload API

POST

/api/upload

Purpose

Upload image to storage.

Flow

Browser

↓

API

↓

Storage

↓

Return URL

Request

multipart/form-data

Response

```json
{
  "success": true,
  "url": "https://storage/image.webp"
}
```

# Pagination

GET /api/packages

Query

?page=1

&limit=10

Example

```json
{
  "success": true,
  "data": [],
  "pagination": {
    "page": 1,
    "limit": 10,
    "total": 100,
    "totalPages": 10
  }
}
```
