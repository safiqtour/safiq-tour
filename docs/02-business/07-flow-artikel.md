# Flow Artikel

## Alur Publikasi Artikel

`
Penulis / Admin membuat draft artikel
        ↓
Memilih kategori & tags
        ↓
Upload thumbnail / hero image
        ↓
Save as DRAFT
        ↓
Review oleh editor (jika ada)
        ↓
Publish / Schedule
        ↓
Artikel tampil di public website
        ↓
Optimasi SEO (meta title, description, keywords)
`

## Struktur Artikel

- Judul
- Slug (auto-generate dari judul)
- Excerpt / ringkasan
- Konten (Rich Text / MDX)
- Thumbnail
- Kategori
- Tags
- Author
- Meta Title
- Meta Description
- Keywords
- Status: DRAFT / PUBLISHED / ARCHIVED
- Published At (jadwal publikasi)

## Aturan

1. Setiap artikel wajib memiliki slug unik
2. Wajib memiliki minimal 1 kategori
3. Meta title dan description wajib untuk SEO
4. Konten mendukung format rich text (Tiptap editor)
