# Flow Jamaah

## Siklus Hidup Jamaah

`
             ┌─────────────────────────┐
             │   Calon Jamaah (Lead)   │
             └──────────┬──────────────┘
                        │ Registrasi / WA
             ┌──────────▼──────────────┐
             │     Prospect            │
             └──────────┬──────────────┘
                        │ Follow Up CS
             ┌──────────▼──────────────┐
             │     Booking             │
             └──────────┬──────────────┘
                        │ Pembayaran DP
             ┌──────────▼──────────────┐
             │  Active (DP Lunas)      │
             └──────────┬──────────────┘
                        │ Pelunasan
             ┌──────────▼──────────────┐
             │  Lunas / Berangkat      │
             └──────────┬──────────────┘
                        │ Selesai Umroh
             ┌──────────▼──────────────┐
             │  Alumni                 │
             └─────────────────────────┘
`

## Status Jamaah

| Status | Deskripsi |
|--------|-----------|
| LEAD | Baru registrasi, belum di follow up |
| PROSPECT | Sudah di follow up, belum booking |
| BOOKED | Sudah booking, belum bayar |
| ACTIVE | Sudah bayar DP |
| PAID | Lunas |
| DEPARTED | Sedang berangkat |
| COMPLETED | Selesai umroh |
| CANCELLED | Dibatalkan |
| REFUND | Mengajukan refund |
