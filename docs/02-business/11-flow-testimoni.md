# Flow Testimoni

## Alur Testimoni

`
Jamaah selesai umroh
        ↓
Admin mengirim permintaan testimoni
        ↓
Jamaah memberikan testimoni (text + foto optional)
        ↓
Admin review testimoni
        ↓
Testimoni dipublikasikan di website
        ↓
Testimoni tampil di halaman publik
`

## Format Testimoni

- Nama jamaah
- Foto (optional)
- Paket yang diambil
- Tanggal keberangkatan
- Rating (1-5 bintang)
- Isi testimoni
- Status: PENDING / APPROVED / REJECTED

## Aturan

1. Testimoni harus melalui review admin sebelum publikasi
2. Testimoni yang direject harus disertai alasan
3. Testimoni dapat difilter berdasarkan paket atau rating
4. Testimoni terbaru ditampilkan di halaman utama
