# Objective

Build a modern Umrah Travel Web Application that is:

- Clean Architecture
- Scalable
- Maintainable
- Vendor Independent
- AI Friendly

Every AI Agent MUST follow this document.

---

# General Rules

## DO

- Write clean code.
- Keep modules independent.
- Prefer composition over inheritance.
- Use TypeScript Strict Mode.
- Keep functions small.
- Write reusable components.
- Validate every input.
- Return typed responses.
- Use environment variables.
- Keep business logic outside UI.

---

## DON'T

- Don't access database from React Components.
- Don't mix UI and business logic.
- Don't hardcode credentials.
- Don't upload files into database.
- Don't duplicate business logic.
- Don't create circular dependencies.
- Don't create huge components.

- Business Rules

- Render UI

---

# Storage Policy

Storage MUST be separated from database.

Database stores:

- filename
- url
- mime type
- size

Binary files MUST NOT be stored inside database.

Supported Storage

- Cloudflare R2
- AWS S3
- MinIO

Storage provider must be replaceable without changing business logic.

---
