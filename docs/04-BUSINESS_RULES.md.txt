# Safiq Tour

Business Rules

Version : 1.0

---

# Purpose

This document defines all business rules for Safiq Tour.

Every feature must follow these rules.

Business Rules have higher priority than implementation.

---

# General Principles

- Validate on server.
- Never trust client input.
- Business Logic lives in Service Layer.
- Repository only accesses database.
- UI never contains business rules.

---

# Authentication Rules

Only Admin can login.

Authentication uses Auth.js.

Password must be hashed.

Never store plaintext password.

Session required for

/admin/**

Public pages never require login.

---

# Package Rules

Every package must have

- Name
- Price
- Airline
- Hotel Makkah
- Hotel Madinah
- Departure Date
- Thumbnail

Package cannot be saved if any required field is missing.

Price must be greater than zero.

Departure Date must be valid.

Package may contain multiple gallery images.

Deleting package also deletes gallery records.

Image files remain in storage until cleanup process.

---

# Gallery Rules

Gallery belongs to exactly one package.

Every gallery image requires

- Package
- Image URL

Gallery cannot exist without package.
