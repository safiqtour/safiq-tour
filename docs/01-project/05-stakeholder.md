# Stakeholder

## Internal

| Stakeholder | Peran | Kepentingan |
|-------------|-------|-------------|
| Owner / Direktur | Pemilik bisnis | Visi strategis, ROI, pertumbuhan bisnis |
| Manajer Operasional | Kepala operasional | Efisiensi workflow, akurasi data |
| Tim IT | Developer & maintenance | Kemudahan pengembangan, dokumentasi |
| Tim Marketing | Promosi & branding | Konten marketing, SEO, campaign |
| Tim Finance | Keuangan & akuntansi | Akurasi transaksi, laporan keuangan |
| Customer Service | Layanan jamaah | Kemudahan akses data jamaah |
| Muthowif / TL | Pembimbing lapangan | Informasi jamaah & jadwal |

## Eksternal

| Stakeholder | Peran | Kepentingan |
|-------------|-------|-------------|
| Calon Jamaah | Pengguna akhir | Informasi jelas, registrasi mudah |
| Jamaah | Pelanggan | Transparansi, kemudahan akses |
| Hotel & Airline | Vendor partner | Data pemesanan, konfirmasi |
| Regulator (Kemenag) | Pengawas | Kepatuhan regulasi |
| Payment Gateway | Penyedia pembayaran | Integrasi pembayaran |
