# Target User

## 1. Internal (Admin / Staff)

### Super Admin
- **Peran**: Pemilik sistem, manajemen puncak
- **Kebutuhan**: Laporan menyeluruh, manajemen user, konfigurasi sistem
- **Akses**: Seluruh fitur

### Admin Operasional
- **Peran**: Staff yang mengelola paket, jadwal, dan konten
- **Kebutuhan**: CRUD paket, galeri, artikel, manajemen jadwal
- **Akses**: Master data, CMS, media

### Finance
- **Peran**: Staff keuangan
- **Kebutuhan**: Manajemen pembayaran, invoice, laporan keuangan
- **Akses**: Data pembayaran, invoice, report keuangan

### Marketing
- **Peran**: Staff marketing dan promosi
- **Kebutuhan**: Manajemen promo, artikel blog, galeri
- **Akses**: CMS, promo, media

### Customer Service
- **Peran**: Front office, layanan jamaah
- **Kebutuhan**: Data jamaah, status booking, dokumen
- **Akses**: Data jamaah, booking, dokumen

### Muthowif / Tour Leader
- **Peran**: Pembimbing ibadah di lapangan
- **Kebutuhan**: Informasi jamaah, jadwal perjalanan, manifest
- **Akses**: Data jamaah (read-only), jadwal

## 2. Eksternal (Public / Jamaah)

### Calon Jamaah
- **Peran**: Pengunjung website
- **Kebutuhan**: Lihat paket, baca artikel, lihat galeri, registrasi
- **Akses**: Seluruh halaman publik

### Jamaah Terdaftar
- **Peran**: Jamaah yang sudah mendaftar dan booking
- **Kebutuhan**: Status booking, riwayat pembayaran, upload dokumen
- **Akses**: Portal jamaah (future phase)
