# Project Vision

STMS bertujuan menjadi platform enterprise utama bagi biro perjalanan umroh di Indonesia. Sistem ini dirancang untuk mengelola seluruh siklus operasional travel umroh — dari pemasaran paket, pendaftaran jamaah, pengelolaan dokumen, pembayaran, hingga keberangkatan dan laporan pasca-perjalanan.

## Prinsip Dasar

1. **Clean Architecture** — Pemisahan layer UI, business logic, dan data access
2. **Security First** — Setiap endpoint diamankan dengan otentikasi dan otorisasi
3. **Data-Driven** — Setiap keputusan bisnis didukung oleh data akurat
4. **User Centric** — Pengalaman pengguna adalah prioritas
5. **Continuous Improvement** — Sistem dirancang untuk terus berkembang
