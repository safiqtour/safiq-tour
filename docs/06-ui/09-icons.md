# Icons

## Library

Menggunakan **Lucide React** sebagai icon library utama.

## Usage

`	sx
import { Users, Package, CreditCard, Settings } from "lucide-react"

// Direct usage
<Users className="w-5 h-5" />

// Dalam button
<Button>
  <Package className="w-4 h-4 mr-2" />
  Package List
</Button>
`

## Icon Sizes

| Context | Size |
|---------|------|
| Button icon | w-4 h-4 |
| List item | w-5 h-5 |
| Navbar | w-5 h-5 |
| Hero / large | w-8 h-8 |
| Feature card | w-10 h-10 |
