# Sprint Roadmap

**Version:** 1.0  
**Total Duration:** ~12 Sprints

---

## Sprint 0 — Foundation (Current)
**Goal:** Architecture, Planning, Documentation
- Project blueprint
- System architecture
- Database ERD
- API contracts
- UI design system
- Development standards
- Security guidelines
- Deployment plan

---

## Sprint 1 — Authentication & Dashboard
**Goal:** Admin access and main dashboard
- Login page UI
- Auth.js integration
- Session management
- RBAC middleware
- Dashboard layout
- Stats widgets
- Recent activity

---

## Sprint 2 — Master Data Management
**Goal:** CRUD for all master data entities
- Country, Region, City management
- Hotel, Airline management
- Facility master
- Package category
- Currency management
- Destination management

---

## Sprint 3 — Package Management
**Goal:** Full package CRUD with related entities
- Package form with wizard
- Package hotel assignment
- Package itinerary editor
- Package schedule management
- Package facility assignment
- Package gallery
- Package status workflow (Draft → Published)

---

## Sprint 4 — CMS (Content Management)
**Goal:** Blog and article management
- Article CRUD with rich text editor (Tiptap)
- Category management
- Tag management
- Author management
- Comment moderation
- SEO fields for articles
- Public article pages

---

## Sprint 5 — Media Library
**Goal:** Centralized media management
- File upload with validation
- Image optimization
- Gallery management
- Media picker component
- Storage abstraction layer (Cloudinary + R2)

---

## Sprint 6 — Booking System
**Goal:** Online booking and registration
- Package public pages with details
- Booking form with pilgrim data
- Booking number generation
- Booking status workflow
- Admin booking management
- WhatsApp notification integration

---

## Sprint 7 — Pilgrim Management
**Goal:** Full pilgrim data and documents
- Pilgrim CRUD
- Document upload (passport, visa, vaccine)
- Document status tracking
- Passport expiry alerts
- Visa application tracking
- Manifest generation

---

## Sprint 8 — Finance & Payment
**Goal:** Payment tracking and invoices
- Payment recording
- Payment verification workflow
- Invoice generation
- Payment status dashboard
- Financial summary reports
- Manual payment proof upload

---

## Sprint 9 — Marketing & Promo
**Goal:** Promotions and marketing tools
- Promo code engine
- Discount management
- Testimonial management
- Newsletter (future)
- SEO optimization tools
- Social media integration

---

## Sprint 10 — Analytics & Reporting
**Goal:** Business intelligence
- Dashboard with charts (Recharts)
- Booking analytics
- Revenue analytics
- Pilgrim demographics
- Export reports (CSV/PDF)
- Custom date range filtering

## Sprint 11 — Mobile Admin
**Goal:** Admin mobile responsiveness
- Mobile-optimized admin interface
- Push notifications
- Quick actions
- Camera for document scan
